# Spec Delta

## ADDED Requirements

### Requirement: 失败反馈保留原因

系统 SHALL 在润色失败、原文注入成功后，通过既有进度事件显示已插入原文和已脱敏的具体失败原因，不将全部失败解释为没有配置模型。

#### Scenario: 鉴权失败

- **WHEN** LLM 返回 401，原文兜底注入成功
- **THEN** 胶囊显示已插入原文以及密钥无效的原因，不显示未配置模型；历史不保存失败的增强结果

#### Scenario: 网络或配置失败

- **WHEN** LLM 网络失败或缺少凭据
- **THEN** 各自显示现有错误原因；没有原因的旧事件显示通用失败提示

#### Scenario: 已取消执行

- **WHEN** 润色期间取消，旧请求随后失败
- **THEN** 不因新错误反馈恢复旧注入或发布旧终态
